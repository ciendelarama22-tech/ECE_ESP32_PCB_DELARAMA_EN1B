# ESP32 Expansion Board

### Project Description
This is a compact and efficient breakout board designed to unlock the full potential of the ESP32 DevKit V1. It serves as a reliable docking base that replaces messy prototyping breadboards by breaking out all GPIO pins to dedicated headers. Designed entirely within EasyEDA, the project spans from initial circuit schematics to final physical PCB routing and 3D prototyping mockup validation.

### Features
* **Perfect Fit**: Tailored explicitly for the physical footprint of the ESP32 DevKit V1.
* **Easy Wiring**: Breaks out all available GPIO pins to eliminate complex prototyping wires.
* **Dual Power Rails**: Integrated routing for dedicated 3.3V and 5V sensor power distribution.
* **Clean Power Filtering**: Employs an AMS1117 regulator alongside filter capacitors to ensure signal stability.
* **Compact Layout**: Low-footprint workspace layout designed for quick and reliable hand-soldering.

### Components Used
* 1 x ESP32 DevKit V1 Microcontroller
* 1 x DC Power Jack (External Input)
* 1 x AMS1117-3.3V Voltage Regulator
* 1 x Slide Switch (Main System Power)
* 1 x 100µF Electrolytic Filter Capacitor
* 1 x 0.1µF Ceramic Bypass Capacitor
* 1 x 0805 SMD LED (Power Indicator)
* 1 x 0805 SMD 1kΩ Resistor (Current Limiting)
* 2 x 1x15 Female Pin Header Strips
* Multi-pin Male Header Strips (GPIO, 3.3V, 5V, GND Breakouts)
